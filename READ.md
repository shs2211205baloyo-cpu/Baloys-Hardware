## About
Baloy's-Hardware is a responsive website for a local hardware store that showcases tools, building materials, paint supplies, and contact information. It provides a simple way for customers to explore the store's products and learn about its services.

## Design System

### Palette (60-30-10)

|   Role   | Share |  Color  |      Used for                  
|----------|-------|---------|---------------------------
| Dominant | 60%   | `Cream` | Main page background 
| Secondary| 30%   | `Beige` | About and contact sections 
| Accent   | 10%   | `Orange`| Buttons, links, and highlights 

### Visual style

**Style chosen:** Minimalism

**Why I chose it:** I chose minimalism to create a clean, organized, and easy-to-navigate website that helps customers focus on the hardware store's products and information.

### Contrast check

**Body text color vs. background color:** `Dark Charcoal` on `Cream`

## Features
- [x] Responsive layout using Tailwind CSS
- [x] Dark mode toggle
- [x] Page-load intro animation using a GSAP timeline
- [x] Scroll reveals using ScrollTrigger
- [x] Scroll progress bar with scrub animation
- [x] Reduced-motion support
- [x] Product cards for tools, building materials, and paint supplies
- [x] Contact form interface
- [x] Replay Intro button

## Built With
- HTML
- Tailwind 
- Script.js
- GSAP
